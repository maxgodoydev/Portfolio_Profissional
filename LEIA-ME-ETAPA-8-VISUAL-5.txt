PENDÊNCIAS TÉCNICAS HONESTAS
- Não foi possível executar npm ci / npm test neste ambiente porque o acesso ao npm registry falhou por DNS (EAI_AGAIN). Portanto, build, typecheck e suíte completa não estão certificados.
- Playwright não foi adicionado ao package.json/package-lock.json porque não foi possível acessar o npm registry. Para executar a auditoria a11y no seu computador, rode na raiz:
    npm ci
    npm install -D playwright
    npx playwright install chromium
    npm test
    npm run build
    npm run preview
  Em outro terminal:
    npm run a11y
  O comando npm install -D playwright atualizará package.json e package-lock.json; inclua os dois arquivos no commit.
- A licença/origem do SVG Excel precisa ser confirmada antes de publicar, se você não tiver essa informação.
- Acessibilidade com leitor de tela e teste em aparelho físico continuam exigindo validação manual.
